 🎮 Tic-Tac-Toe Game (XO)

A simple Tic-Tac-Toe game developed using Java Swing.

 Features
- Two players (X and O).
- Custom player names.
- Score tracking.
- Turn management.
- Winner detection.
- Game reset.

  Technologies
- Java
- Java Swing
- Object-Oriented Programming (OOP)

 📚 What I Learned
- Working with Java classes and objects.
- Using arrays and loops.
- Building graphical user interfaces using Swing.
- Handling button events.
- Applying Object-Oriented Programming concepts.
